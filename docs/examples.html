    ##A small annotated starter

    html
    <main id="showcase">
  <section data-swarmtroopers-section="An introduction">
    <h1 data-swarmtroopers="type">Make room for good ideas.</h1>
    <article data-swarmtroopers="frame">A thoughtfully framed card.</article>
    <hr data-swarmtroopers="rule">
    <ul data-swarmtroopers="repeat">
      <li>One idea</li><li>Another idea</li><li>Something clicks</li>
    </ul>
  </section>
</main>
<script src="https://unpkg.com/swarmtroopers@0.5.1/dist/swarmtroopers.core.iife.js"
  data-swarmtroopers-init='{"root":"#showcase","inspect":true,"controls":true}'></script>

    Add your normal typography, spacing, card surfaces, and list styling. The annotations choose tools; they do not replace the host design.

    ##Start on an intentional action

    Manual mode collects and hides selected elements before starting. Keep the start button outside the root, avoid hiding essential content, and consider whether a static preview is a better initial state for your audience.

    javascript
    const swarmtroopers = create({
  root: '#showcase',
  auto: true,
  trigger: 'manual',
});

document.querySelector('#start-demo').addEventListener('click', () => {
  swarmtroopers.start();
}, { once: true });

    ##Completion behavior

    The closing clap plays after a natural build with at least one spawned agent, where the orchestrator stands; the center of the viewport is only a fallback. Two pixel cursor hands, seen from the side and drawn at 2×, arrive, pull back, swing, slap with a small burst, bounce and rest. Each hand has its agent’s name tag under it: the last worker on the left, the orchestrator on the right. There is no panel or veil, so the page stays fully visible, and the clap never catches the pointer.

    finale: false disables it; finish() reveals content without playing it. A deliberate wheel, touch, click, or key dismisses it after its initial half-second. It clears automatically after 3.54 seconds.

    Try the compact completion example. This is a behavior reference, not a required section of your website.
