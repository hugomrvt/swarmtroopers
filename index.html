four tools

Picked from your markup. Text gets typed, boxes get framed, lines get drawn, lists get stamped.

Made with careada type
type(el, text)

Words with a human rhythm

A click, a caret, a short pause. Text appears where it already sits, so the layout never jumps.

mia frame
frame(el)

A precise drag for every box

Cards, images and fields open from one corner to the other, then release.

noé rule
rule(el)

Lines drawn end to end

Separators and borders get one steady stroke.

iris stamp
stamp(list)

Lists pressed into place

The first item is framed. The rest follow it, one stamp at a time.

install

npm i swarmtroopers.
or one script tag.

Keep your markup. Install the package, point it at your main element, and the agents do the rest. Working with Claude Code? One command installs the integration skill, then ask it to add Swarm Troopers to your page.

install
// npm i swarmtroopers
import { create, controls } from 'swarmtroopers';

const swarmtroopers = create({
  root: 'main',
  auto: true,
  inspect: true,
});

controls(swarmtroopers);
npm i swarmtroopers. Create on mount. Call swarmtroopers.destroy() when the view unmounts.
